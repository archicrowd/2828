Erandeid ei ole, kuid üleminek on õiglane

Praegune ärivara soodustus mõjub kõige tugevamalt seal, kus lähevad üle suurimad varandused. See kaob asendamata. Kes pärib ettevõtte või maja, seisab seega maksu ees varalt, mis ei ole raha.

Selle asemele tuleb ajatamine. Intressi arvestatakse esmalt määraga, millega riik ise end refinantseerib; kümne aasta jooksul tõuseb määr turu laenuintressini. Jooksvalt tuleb tasuda üksnes intressi. Kes ka seda kanda ei suuda, sellele liidetakse see tasumata jäägile. See jääk jääb koormiseks päritud esemele ja muutub sissenõutavaks selle müügil või edasiandmisel.

Nii ei pea keegi müüma, et maksu tasuda – ja kellelegi ei kingita midagi. Midagi ei kustutata, midagi ei saa aeguda. Ajatamine jääb ajatamiseks.

Miks eelarve ümber ei lähe

Kavand on täpselt nii hea kui tema kaitsemehhanismid. Otsustavad viis reeglit — mitte valimisvõitlus.

Kõigepealt tulud.

Kontserne, platvorme, kapitali, pärandusi, suuri varasid ja maad maksustatakse uue õiguse järgi mitu kuud enne esimest väljamakset. Dividend algab puhvrilt, mitte kunagi laenult.

Valem, mitte kalender.

Dividend on pool ametlikust elatusmiinimumist. See tõuseb astmeti kuni 60 %-ni kohe, kui kriisireserv on täis ja investeeringud kindlustatud.

Mitte kunagi kärpida — üksnes peatada.

Kui reservi puudutatakse, peatub ainult iga-aastane korrigeerimine. Järele jõutakse üksnes ülejääkidest.

2 % SKPst seisab kriisireservina; lisaks läheb igal aastal kuni 1 % SKPst koolidesse, võrkudesse ja raudteedesse. Riik jääb tegutsemisvõimeliseks ilma uue võlata.

Üheksa langetavad, üks tõstab

Üheksas riigis kümnest langeb tulumaksu tipumäär, Taanis 32 punkti võrra. Ainult Eesti peaks tõstma, 24-lt 28 %-le. Ettevõtte tulumaksuga on vastupidi: see tõuseb üheksas riigis — Iirimaal 15,5 punkti võrra — ja langeb ainult Saksamaal.

Üheksast piisab, kümme on arvutatud

ELi lepingu tõhustatud koostöö nõuab vähemalt üheksat liikmesriiki. Klubi saaks seega alustada ELi õiguse sees, ootamata kõigi 27 üksmeelt. Kümme riigifaili tähendab, et üks riik võib loobuda, ilma et tee sulguks.

Tõmme väljastpoolt

Kuna tipumäärad langevad kogu klubis, muutub see ahvatlevamaks suurtele sissetulekutele ja ettevõtete asutamisele — vastukaal lahkumisele vara- ja pärandimaksu tõttu.

Miks Eesti on klubis

1,4 miljoni elanikuga on Eesti väikseim liige — ja täna 28:28 ehituspõhimõttele kõige lähemal.

  • Alates 2026. aasta jaanuarist kehtib üks 24 % määr tulule, jaotatud kasumile ja käibemaksule. See on sisuliselt 24:24.
  • Maamaks põhineb alates 1993. aastast üksnes maa väärtusel; hooneid ei maksustata. See on osa 04, töös üle kolmekümne aasta.
  • Maksudeklaratsioon esitatakse digitaalselt minutitega — osa 01 halduslik eeldus.
  • 24,1 %-ga on Eestil ELi madalaim võlakoormus: pilootriik suurima ruumi ja väikseima riskiga.

Kõige raskem juhtum: Iirimaa

Iirimaa on selles loendis, sest kavand ei tohi praeguse süsteemi võitjaid varjata. Varajase ühinejana on ta ühtlasi kümnest kõige ebatõenäolisem.

  • Ettevõtte tulumaks peaks tõusma 12,5-lt 28 %-le — suurim üksiksamm kogu loendis. Iiri kasumimaks on pealegi äärmiselt koondunud: Iiri eelarvenõukogu andmetel maksid 2024. aastal kolm kontserni sellest ligikaudu 46 %, umbes 13 mld eurot.
  • Iiri SKP on kontsernide raamatupidamise tõttu ülepaisutatud. Muudetud kogurahvatulu GNI* järgi, mille Iiri statistikaamet just sel põhjusel avaldab, maksab dividend 10,2 % — sama palju kui Saksamaal, mitte 5,6 %, nagu SKP näib osutavat.
  • Osa 05 ei vaja Iirimaad. Maksustatakse seal, kus toimub müük, sõltumata sellest, kus kasum on kirjendatud. Osa mõjub ühepoolselt — selles ongi tema mõte. Iirimaa liitumine annab midagi muud: õigusrahu ELi sees menetluse asemel liikmesriigi vastu.
  • Iiri elanikkonna jaoks oleks arvestus soodne: tipumäär 48-lt 28 %-le, dividend 626 eurot kuus. Kaotsi läheks riigitulu allikas, mis sõltub vähestest välismaistest kontsernidest — mitte inimeste heaolu.

Mida see arvutus ei tee: mitme riigi mudelit ei ole. Arvutatud on üksnes dividendi brutokulu riiklike sissetulekutasemete juures; astmestiku tulu, ettevõtted, tarbimine, maa, CO₂ ja maksete ümberkorraldus ei ole riigiti modelleeritud. Olemasolevad toetused ja maksesüsteemid erinevad tugevalt — Taani ja Eesti rahastavad oma sotsiaalriiki peamiselt maksudest, nii et hoob „maksete langetamine” sealt suuresti puudub. Belgia, Iirimaa ja Holland kaotaksid kliendi asukohas maksustamisest tulu, mida siin ei ole tasaarvestatud. Ostujõu erinevusi ei ole arvutatud. Kindlaks muutub see alles EUROMODiga, mis kujutab kõiki maksu- ja toetussüsteeme ühel alusel.

Rechtsstand "heute": 2026 (§ 32a EStG 2026, SV-Rechengroessen 2026, Soli-Freigrenze 2026, Kindergeld 259 EUR).

gegen diese niedrigere Modellbasis gerechnet -> konservativ (Kostenanteil eher ueberzeichnet).

MWST_GEWICHTE = [.10, .10, .20, .30, .30]                      # ANNAHME Konsumanteile

ERB_FREIBETRAG_KIND = 400000
KINDER_MIO, ERW_MIO = 14, 70

BBG_KV, BBG_RV = 69750, 101400
AN_KV_PV = 0.073 + 0.0145 + 0.018           # KV 7,3 + halber durchschn. Zusatzbeitrag 1,45 + PV 1,8
AN_KINDERLOS = 0.006
AN_RV_AV = 0.093 + 0.013
KINDERGELD = 259
WK_PAUSCH, SA_PAUSCH = 1230, 36
SOLI_FG = 20350

# 1  STEUER- UND ABGABENFUNKTIONEN

def est_2026(zve):
    zve = math.floor(max(0, zve))
    if zve <= 12348: return 0.0
    if zve <= 17799: y = (zve-12348)/1e4; return math.floor((914.51*y+1400)*y)
    if zve <= 69878: z = (zve-17799)/1e4; return math.floor((173.10*z+2397)*z+1034.87)
    if zve <= 277825: return math.floor(0.42*zve-11135.63)
    return math.floor(0.45*zve-19470.38)

def soli_2026(est, split=False):
    fg = SOLI_FG*(2 if split else 1)
    if est <= fg: return 0.0
    return min(0.055*est, 0.119*(est-fg))

def sv_heute(b, kinderlos=True):
    kvpv = (AN_KV_PV + (AN_KINDERLOS if kinderlos else 0))*min(b, BBG_KV)
    return kvpv + AN_RV_AV*min(b, BBG_RV)

def netto_heute(b, kinder=0, partner=False):
    sv = sv_heute(b, kinderlos=(kinder == 0))
    zve = max(0, b - sv - WK_PAUSCH*(b > 0) - SA_PAUSCH*(2 if partner else 1))
    est = 2*est_2026(zve/2) if partner else est_2026(zve)
    soli = soli_2026(est, partner)
    return dict(netto=b - sv - est - soli + kinder*KINDERGELD*12, est=est+soli, sv=sv)

def est_2828(x, saetze=TARIF_SAETZE, grenzen=TARIF_GRENZEN):
    s, prev = 0.0, 0.0
    for g, r in zip(grenzen, saetze):
        if x > prev: s += (min(x, g)-prev)*r
        prev = g
        if x <= g: break
    return s

def netto_2828(b, kinder=0, partner=False, anteil=50):
    dd = DD_EUR[anteil]*12
    sv = SV_AN[anteil]*b                          # keine Bemessungsgrenzen
    est = est_2828(b + dd)                        # DD steuerpflichtig, Individualbesteuerung
    kind = kinder*DD_EUR[anteil]*KIND_ANTEIL*12   # Kinder-DD steuerfrei (Annahme)
    p = 0.0
    if partner: p = dd - est_2828(dd)             # Partner: eigene DD, eigene Veranlagung
    return dict(netto=b - sv - est + dd + kind + p, est=est, sv=sv, dd=dd + kind + p)

def r_eff_mwst(stufen=MWST_STUFEN):
    return sum(w*s for w, s in zip(MWST_GEWICHTE, stufen))/100
R_EFF_HEUTE = 0.165                               # Projektannahme effektiver Satz heute

def konsumquote(n): return .95 if n < 25000 else .85 if n < 50000 else .75 if n < 80000 else .60
def mwst_mehrbelastung(netto):
    r = r_eff_mwst()
    return netto*konsumquote(netto)*(r/(1+r) - R_EFF_HEUTE/(1+R_EFF_HEUTE))

def est_aufkommen(anteil, eti):
    dd = DD_EUR[anteil]*12; tot = 0.0
    for mio, b in VERT:
        m0, m1 = _grenz(b+dd, S25, G25), _grenz(b+dd, TARIF_SAETZE, TARIF_GRENZEN)

        tot += mio*est_2828(b1+dd)/1000

def mwst_aufkommen(leak):
    r0 = 0.18; brutto = 350/(r0/(1+r0)); r1 = r_eff_mwst()
    return 350 + (brutto*r1/(1+r1) - 350)*leak

def einnahmen(anteil, sc, detail=False):

    d = {

     'Vermögen-Mindeststeuer (anrechenbar)':  22*(1-0.02*(L-25)),
     'CO₂-Abgabe 100 €/t (netto)':            55,
     'Sonstige Steuern':                      165,

    return (sum(d.values()), d) if detail else sum(d.values())

def simuliere(sc, mit_bausteinen=True, jahre=20):
    g_e = sc['g_e'] - sc['drag']*(L-25); g_a = sc['g_a'] - 0.5*sc['drag']*(L-25)
    E = {a: einnahmen(a, sc) for a in STUFEN}
    F, i, idx, idx_voll, letzter_schritt, rows = STARTPUFFER, 0, 1.0, 1.0, -99, []
    for t in range(jahre):
        bip = BIP0*(1+g_e)**t
        if t > 0: idx_voll *= 1+sc['dd_idx']
        def saldo(a, ix):
            e = (E[a] + (bausteine(t)*sc['hc'] if mit_bausteinen else 0))*(1+g_e)**t*sc['schock'].get(t,1.0) \
                + (sc['verh'] if t >= 2 else 0)
            x = AUSG[a]; aus = (x['basis']+x['zusch']+x['haerte'])*(1+g_a)**t + dd_kosten(a)*ix + sc['schock_a'].get(t,0)
            return e - aus
        # Regel 3: jaehrliche Anpassung an das Existenzminimum, solange der Puffer nicht angegriffen ist;
        #          ausgesetzte Anpassungen werden nur aus Ueberschuessen nachgeholt
        if t > 0 and F >= PUFFER*bip:
            idx *= 1+sc['dd_idx']
            if idx < idx_voll - 1e-9:
                kosten = dd_kosten(STUFEN[i])*(idx_voll-idx)
                if saldo(STUFEN[i], idx_voll) >= INV*bip and F - PUFFER*bip - INV*bip >= 2*kosten: idx = idx_voll
        # Regel 2: Aufstieg 50->55->60 %, fruehestens Jahr 3, Abstand >= 2 Jahre
        rest = max(F - PUFFER*bip, 0)
        if i < 2 and t >= 2 and t - letzter_schritt >= 2 and F >= PUFFER*bip \
           and saldo(STUFEN[i+1], idx) + rest/10 >= INV*bip:
            i += 1; letzter_schritt = t
        S = saldo(STUFEN[i], idx); F += S
        luecke = F < 0
        inv = min(max(F - PUFFER*bip, 0), INV*bip); F -= inv
        rows.append(dict(jahr=START+t, t=t+1, anteil=STUFEN[i], dd=DD_EUR[STUFEN[i]]*idx, dd_2026=DD_EUR[STUFEN[i]]*idx/idx_voll, dd_real=idx/idx_voll,
                         saldo=S, inv=inv, ziel=INV*bip, fonds=F, luecke=luecke, bip=bip))
    return rows

                dd_real_min=min(r['dd_real'] for r in rows)*1.0)
