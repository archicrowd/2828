Ninguna exención, pero una transición justa

La exención actual de los activos empresariales actúa con más fuerza allí donde cambian de manos los mayores patrimonios. Se suprime sin sustituto. Quien hereda una empresa o una vivienda se enfrenta por tanto a un impuesto sobre bienes que no son dinero.

En su lugar entra un aplazamiento. Devenga intereses al principio al tipo al que el Estado se refinancia; a lo largo de diez años el tipo sube hasta el tipo de crédito de mercado. Sólo los intereses son exigibles de forma corriente. A quien no pueda soportar ni eso, se le añaden al saldo pendiente. Ese saldo queda como carga sobre el bien heredado y vence cuando se vende o se transmite.

Así nadie tiene que vender para pagar el impuesto, y a nadie se le regala nada. No se condona nada ni puede prescribir nada. El aplazamiento sigue siendo un aplazamiento.

Por qué el presupuesto no puede volcar

Un proyecto vale lo que valen sus salvaguardas. Deciden cinco reglas, no las campañas electorales.

Primero los ingresos.

Empresas, plataformas, capital, herencias, grandes patrimonios y suelo tributan con el nuevo derecho varios meses antes del primer pago. El dividendo arranca sobre un colchón, nunca a crédito.

Fórmula en vez de calendario.

El dividendo equivale a la mitad del mínimo vital oficial. Sube por escalones hasta el 60 % en cuanto la reserva de crisis está llena y la inversión asegurada.

Nunca recortar, solo pausar.

Si se toca la reserva, solo se suspende la actualización anual. La recuperación se hace únicamente con superávits.

Reserva y fondo de inversión.

Un 2 % del PIB está listo como reserva de crisis; más allá, hasta un 1 % del PIB va cada año a escuelas, redes y ferrocarril. El Estado mantiene su capacidad de actuar sin deuda nueva.

Consejo fiscal, cifras abiertas, corredor fijo.

Un consejo independiente revisa cada año todos los supuestos; las cifras reales son públicas cada mes. Como última salvaguarda, el tipo único solo puede deslizarse por regla, entre el 25 y el 30 %.

Nueve bastan, diez están calculados

La cooperación reforzada del Tratado de la UE exige al menos nueve Estados miembros. El club podría por tanto arrancar dentro del derecho de la Unión, sin esperar la unanimidad de los veintisiete. Diez archivos por país significa que un país puede retirarse sin bloquear el camino.

Movilidad dentro del club

El dividendo va de 306 € en Estonia a 651 € en Austria; en poder adquisitivo la distancia es menor. Para quien trabaja rige la plena igualdad de trato. Para la llegada sin ingresos del trabajo habría que examinar un plazo de espera como el que Alaska aplica a su dividendo.

Atracción desde fuera

Como los tipos máximos bajan en todo el club, este resulta más atractivo para rentas altas y para crear empresas: un contrapeso a la salida provocada por los impuestos sobre patrimonio y sucesiones.

Por qué Estonia está en el club

Con 1,4 millones de habitantes, Estonia es el miembro más pequeño y hoy el más cercano al principio constructivo de 28:28.

  • Desde enero de 2026 rige un tipo del 24 % para la renta, para los beneficios distribuidos y para el IVA. Es de hecho un 24:24.
  • El impuesto inmobiliario se calcula desde 1993 solo sobre el valor del suelo; los edificios no tributan. Es el elemento 04, funcionando desde hace más de treinta años.
  • La declaración se presenta digitalmente en minutos: el requisito administrativo del elemento 01.
  • Con un 24,1 %, Estonia tiene la deuda más baja de la UE: el país piloto con más margen y menos riesgo.

El caso más difícil: Irlanda

Irlanda figura en esta lista porque un proyecto no debe ocultar a los ganadores del sistema actual. Como candidato temprano es, al mismo tiempo, el menos probable de los diez.

  • El impuesto de sociedades tendría que subir del 12,5 al 28 %, el mayor salto de toda la lista. Además, el impuesto irlandés sobre beneficios está extremadamente concentrado: según el consejo fiscal irlandés, en 2024 tres grupos pagaron alrededor del 46 %, unos 13.000 millones de euros.
  • El PIB irlandés está inflado por la contabilidad de las multinacionales. Medido sobre la renta nacional bruta modificada, RNB*, que el instituto estadístico irlandés publica precisamente por eso, el dividendo cuesta un 10,2 %: lo mismo que en Alemania, y no el 5,6 % que sugiere el PIB.
  • El elemento 05 no necesita a Irlanda. Se tributa donde se vende, con independencia de dónde se contabilice el beneficio. El elemento actúa de forma unilateral: ese es su sentido. La adhesión irlandesa aporta otra cosa: paz jurídica dentro de la UE en vez de un procedimiento contra un Estado miembro.
  • Para la población irlandesa el cálculo sería favorable: tipo máximo del 48 al 28 %, dividendo de 626 € al mes. Lo que se perdería es una fuente de ingresos del Estado que depende de unos pocos grupos extranjeros, no el bienestar de las personas.

Lo que este cálculo no hace: no existe un modelo multipaís. Solo se calcula el coste bruto del dividendo con los niveles de renta nacionales; la recaudación de la tarifa, las empresas, el consumo, el suelo, el CO₂ y la reforma de las cotizaciones no están modelados país por país. Las prestaciones y los sistemas de cotización existentes difieren mucho: Dinamarca y Estonia financian su Estado social sobre todo con impuestos, de modo que allí falta en gran medida la palanca de «bajar cotizaciones». Bélgica, Irlanda y los Países Bajos perderían recaudación por la tributación en el lugar del cliente, algo que aquí no se compensa. No se han calculado las diferencias de poder adquisitivo. Esto solo será sólido con EUROMOD, que representa todos los sistemas fiscales y de transferencias sobre una misma base.

def est_2026(zve):
    zve = math.floor(max(0, zve))
    if zve <= 12348: return 0.0
    if zve <= 17799: y = (zve-12348)/1e4; return math.floor((914.51*y+1400)*y)
    if zve <= 69878: z = (zve-17799)/1e4; return math.floor((173.10*z+2397)*z+1034.87)
    if zve <= 277825: return math.floor(0.42*zve-11135.63)
    return math.floor(0.45*zve-19470.38)

def soli_2026(est, split=False):
    fg = SOLI_FG*(2 if split else 1)
    if est <= fg: return 0.0
    return min(0.055*est, 0.119*(est-fg))

def sv_heute(b, kinderlos=True):
    kvpv = (AN_KV_PV + (AN_KINDERLOS if kinderlos else 0))*min(b, BBG_KV)
    return kvpv + AN_RV_AV*min(b, BBG_RV)

def netto_heute(b, kinder=0, partner=False):
    sv = sv_heute(b, kinderlos=(kinder == 0))
    zve = max(0, b - sv - WK_PAUSCH*(b > 0) - SA_PAUSCH*(2 if partner else 1))
    est = 2*est_2026(zve/2) if partner else est_2026(zve)
    soli = soli_2026(est, partner)
    return dict(netto=b - sv - est - soli + kinder*KINDERGELD*12, est=est+soli, sv=sv)

def est_2828(x, saetze=TARIF_SAETZE, grenzen=TARIF_GRENZEN):
    s, prev = 0.0, 0.0
    for g, r in zip(grenzen, saetze):
        if x > prev: s += (min(x, g)-prev)*r
        prev = g
        if x <= g: break
    return s

def netto_2828(b, kinder=0, partner=False, anteil=50):
    dd = DD_EUR[anteil]*12
    sv = SV_AN[anteil]*b                          # keine Bemessungsgrenzen
    est = est_2828(b + dd)                        # DD steuerpflichtig, Individualbesteuerung
    kind = kinder*DD_EUR[anteil]*KIND_ANTEIL*12   # Kinder-DD steuerfrei (Annahme)
    p = 0.0
    if partner: p = dd - est_2828(dd)             # Partner: eigene DD, eigene Veranlagung
    return dict(netto=b - sv - est + dd + kind + p, est=est, sv=sv, dd=dd + kind + p)

def r_eff_mwst(stufen=MWST_STUFEN):
    return sum(w*s for w, s in zip(MWST_GEWICHTE, stufen))/100
R_EFF_HEUTE = 0.165                               # Projektannahme effektiver Satz heute

            e = (E[a] + (bausteine(t)*sc['hc'] if mit_bausteinen else 0))*(1+g_e)**t*sc['schock'].get(t,1.0) \

        # Regel 2: Aufstieg 50->55->60 %, fruehestens Jahr 3, Abstand >= 2 Jahre
        rest = max(F - PUFFER*bip, 0)
        if i < 2 and t >= 2 and t - letzter_schritt >= 2 and F >= PUFFER*bip \
           and saldo(STUFEN[i+1], idx) + rest/10 >= INV*bip:

        S = saldo(STUFEN[i], idx); F += S
        luecke = F < 0
        inv = min(max(F - PUFFER*bip, 0), INV*bip); F -= inv
        rows.append(dict(jahr=START+t, t=t+1, anteil=STUFEN[i], dd=DD_EUR[STUFEN[i]]*idx, dd_2026=DD_EUR[STUFEN[i]]*idx/idx_voll, dd_real=idx/idx_voll,

const P = {
  exmin: 12348, dd: {50: 515, 55: 566, 60: 617}, kindAnteil: 0.5,
  tarifGrenzen: [12348, 25000, 40000, 55000, 70000, Infinity],

  kindergeld: 259, wk: 1230, sa: 36, soliFG: 20350

function est2026(zve){ zve=Math.floor(Math.max(0,zve));
  if(zve<=12348) return 0;
  if(zve<=17799){const y=(zve-12348)/1e4; return Math.floor((914.51*y+1400)*y);}

  return Math.floor(.45*zve-19470.38); }
function soli2026(e,split){const fg=P.soliFG*(split?2:1); return e<=fg?0:Math.min(.055*e,.119*(e-fg));}
function heute(b,kinder,partner){
  const sv=(P.anKVPV+(kinder===0?P.anKinderlos:0))*Math.min(b,P.bbgKV)+P.anRVAV*Math.min(b,P.bbgRV);
  const zve=Math.max(0,b-sv-(b>0?P.wk:0)-P.sa*(partner?2:1));
  const e=partner?2*est2026(zve/2):est2026(zve); const s=soli2026(e,partner);
  return {netto:b-sv-e-s+kinder*P.kindergeld*12, steuer:e+s, sv:sv};
}
function est2828(x){let s=0,prev=0;
  for(let i=0;i<P.tarifSaetze.length;i++){const g=P.tarifGrenzen[i];
    if(x>prev) s+=(Math.min(x,g)-prev)*P.tarifSaetze[i]; prev=g; if(x<=g) break;}
  return s;}
function neu(b,kinder,partner,anteil=50){

}
