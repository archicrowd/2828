# Lizenz: Vorschlag, keine Festlegung

Stand: 6. Oktober 2026. Dies ist eine Entscheidungsvorlage des Bearbeiters, **keine Rechtsberatung**.
Eine Lizenz ist eine rechtliche Erklärung des Autors; sie wird hier nicht in seinem Namen gesetzt.

| Teil | Vorschlag | Anmerkung |
|---|---|---|
| Skripte (`modell/`, `projekt/`, `schnittstelle/`) | MIT oder Apache-2.0 | erlaubt Nachnutzung durch Dritte, einschließlich Mikrosimulation |
| Texte und Dokumente (`logbuch/`, `dokumente/`) | CC BY 4.0 | Namensnennung, Bearbeitung erlaubt |
| Ergebnisdateien (`daten/aggregate/`) | CC BY 4.0 | Quellenvorbehalte der Eingangsdaten gelten weiter |
| Daten Dritter | keine eigene Lizenz | Taxplorer CC BY-NC-ND 4.0 (keine Weitergabe), OECD, Eurostat nach deren Bedingungen; Drittdateien nur als Manifest |
| Webseite (`seite/`) | wie Texte | Impressum nennt eine Person |

Offene Fragen: Soll das Repository öffentlich werden? Dann stünden Name im Impressum der Seite, die
Rechnungen und alle Entwürfe öffentlich; die `noindex`-Sperre der Seite gilt nicht für das Repository.
Beiträge Dritter brauchen eine Erklärung zur Lizenz ihres Beitrags (Vorschlag: gleiche Lizenz wie das Projekt).
